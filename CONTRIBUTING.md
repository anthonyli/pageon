# Contributing

Issues and pull requests are welcome. Describe the problem, the proposed change and how you verified it. For larger changes, open an issue to discuss the approach first.

Run `npm test` and `npm run build`. Include a small original HTML fixture for compatibility reports; do not attach private documents, credentials or paid templates. For contributions to the official distribution, keep the default PageOn attribution and fixed destination. This is a project acceptance policy, not an additional restriction on the rights granted by the MIT License.

This distribution is licensed under the MIT License. By submitting a contribution for inclusion, you agree to license it under the same terms. Retain existing copyright and third-party notices.

The root `examples/` HTML files are generated and included in the distribution for immediate use. Edit the shared sample or Runtime source, run `npm run build:runtime`, and include the regenerated examples with the change. Do not maintain a separate implementation inside generated HTML.
